Generate SEO titles and meta descriptions with AI. Live preview, 0-100 score, keyword checks, and bulk actions.
== Description ==
Generate SEO-friendly titles and meta descriptions with one click. The plugin scores each snippet (0–100), validates keyword usage, and supports bulk actions for posts and taxonomies.
== Installation ==
1. Upload and activate the plugin.
2. Go to **AI Snippet SEO Pro → Site Key Management** and paste your Site Key.
3. Optional: enable **Auto-update slug** and choose a model.
4. Open a post or term and click **Generate with AI**.
